# Chameleon design taste

Keep the supplied design recognizable across canvases and keep the local studio
useful for evaluating that result. Derive design decisions from the original
source and the user's current direction.

## Source design

For engine geometry, typography, candidate selection, scoring, or rendered
fidelity, read [source-style](references/source-style.md). Capture the source's
visual relationships before changing its layout. Compare real source and result
renders after each meaningful change.

## Local GUI

For viewer controls, previews, inspection, imports, or exports, read
[GUI taste](references/gui-taste.md). Keep the interface consistent with the
existing product and make its current task, output, and state clear.

Apply both branches when a change spans engine output and the viewer. Respect
the requested scope and existing authorization; this skill adds quality guidance,
not an additional approval step.
