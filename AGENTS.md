# Chameleon project guidance

For engine, model, renderer, or submission changes, read [RULES.md](RULES.md)
and [FAQ.md](FAQ.md) before implementation. Preserve their stage-one contract,
including offline execution and the intentional missing-asset placeholder.
Follow the current [submission scope](docs/SUBMISSION_CHECKLIST.md): prioritize
the final brief's offline stage-one engine; the user has deferred Adobe host
testing. Retain the FAQ viewer discrepancy without treating it as resolved.
Report unverified requirements separately from passing checks.

For changes or reviews affecting resized design quality, read
[chameleon-design-taste](.agents/skills/chameleon-design-taste/SKILL.md) and follow
its **Source design** branch.

For local viewer interface work, read the same skill and follow its
**Local GUI** branch. Apply both branches when the change affects both surfaces.
