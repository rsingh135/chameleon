Compatibility

This development add-on uses experimental image export. Unsupported masks, effects, fonts and group deformation stop the operation. The source page is preserved.

Adobe and local text rasterizers can differ. Exact font files are required; native host rendering must still be checked. Image-resource export cannot inspect externally applied filters in the current SDK.
