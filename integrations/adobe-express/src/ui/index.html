    About this viewer

    This stage-one viewer displays the engine’s real JSON and PNG outputs. Adding the PNG places a rendered image; it does not create editable text or shapes.

    Task imports use the engine’s supplied brand-kit assets and fonts. Missing artwork uses the documented placeholder. Custom resource packages belong to the separate native development integration.

    Local quality checks are diagnostics, not the official competition score.
